# Marketing_league

AI Powered Real-Time Cricket Marketing Platform for Indian Brands 🚀🏏

Marketing_league detects live cricket match moments and instantly generates AI-powered Hinglish branded creatives for Telegram audiences.

The platform transforms live cricket emotions into automated marketing opportunities for local businesses, startups, and D2C brands.

--

# Features

- Real-time cricket event detection
- AI generated Hinglish captions
- Automated branded creative generation
- Instant Telegram delivery
- Meme-style marketing automation
- Built for IPL engagement
- Low-cost marketing for local brands

# Tech Stack

| Component | Technology |
|---|---|
| Match Scores API | Self Hosted Cricket API |
| Workflow Automation | n8n |
| AI Caption Generation | Gemini AI |
| HTML to Image Rendering | hcti.io |
| Messaging Platform | Telegram Bot API |
| State Management | Excel |
| Brand Data Management | Google Sheets |

---

# System Flow

```text
Live Match API
      ↓
Event Detection (n8n)
      ↓
Check Previous Event (Excel)
      ↓
Fetch Brand Data (Google Sheets)
      ↓
Generate Hinglish Caption (Gemini AI)
      ↓
Generate Creative Card (HTML + hcti.io)
      ↓
Send via Telegram Bot
      ↓
Fans Receive Instant Creative
```
